# Engineered depleted-bulk control

Before execution: in the oxygenated 4 um world, print the actual initial O2 molecule count, then deliberately set that private scavenger pool to exactly 1,000,000 molecules and set the other mutable scavenger pools to zero for a controlled test. This is an engineered depleted background, not a prediction that 40 ns of beam chemistry depleted the oxygen pool. Use a one-cell mesh, one e_aq source, advance through the next reaction event, and record the O2 pool and global-propensity-refresh count. Reconstruct the remaining old tracked products as particles, stage a fresh e_aq one picosecond later, and run one shared particle phase with `ResetScavenger(false)`. Assert the depleted pool identity and count survive this phase. Transfer the particle survivors back to the mesh, advance through the next reaction, and record the pool and refresh count again. For the selected fixed seed, require each event to consume exactly one O2 molecule and trigger a whole-queue refresh; pool identity and count must persist across source insertion. The event-peek and refresh counters are experimental instrumentation and do not change random sampling. The test does not validate the physical stochastic per-cell bulk approximation or full irradiation depletion.
