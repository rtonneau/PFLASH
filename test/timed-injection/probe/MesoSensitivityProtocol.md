# Additional sensitivity protocol

Before these runs: extend the existing 4 um oxygen-free one-at-a-time sensitivity matrix with a 150 ps handover at 25 nm and a 100 ps handover at 12.5 nm. Use the first eight independent library/holdout pairs, four paired chemistry seeds `81001+i*101+r*1009`, 199 ps delay and 203 ps endpoint, with the same reference and baseline as the earlier 50/100 ps and 25/50 nm tests. The 12.5 nm mesh must pass `CheckingReactionRadius` before any chemistry runs; an invalid resolution is reported as unavailable, not ignored. Stop a process if its working set exceeds 1 GiB or system free memory falls below 3 GiB. Report all completed and censored cases and t7 paired cluster uncertainty. Three sampled values provide a trend, not an automatic convergence claim.
The predeclared 12.5 nm setting failed the explicit reaction-radius gate before chemistry: one reported offending radius is 4.5117 nm, requiring a cell width greater than pi times that radius (about 14.17 nm). It is retained as an invalid setting. Before further runs, use 20 nm cells (200 per side) as the third candidate, subject to the same radius gate; no automatic mesh coarsening is used in this experiment.
