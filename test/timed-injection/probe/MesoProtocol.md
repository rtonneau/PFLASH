# Mesoscopic coupling probe protocol (pre-comparison)

Candidate: advance one persistent RDME mesh to the next actual source time. Reconstruct every old tracked count at independently sampled positions uniformly within its own cell, retaining the same bulk material. Insert exact fresh precursor tracks and evolve the entire old+new population in one particle scheduler. Simultaneous and close subsequent arrivals join that same live particle history; transfer all survivors together to the mesh only when the declared maturation interval has elapsed and no unprocessed precursor state remains. Source at a boundary precedes observation; no later source is activated early. A separately seeded reconstruction stream must not consume the source-selection or chemistry random stream. All particle IDs must be unique; the bulk pool and absolute time must persist. Stable-species-only diagnostics do not establish precursor fidelity.

The model loses within-voxel spatial correlations on each reconstruction. Maturation delay, cell width, boundary handling and the frequency of whole-state reconstruction are model parameters, not accuracy guarantees. Compare against the ticket-2 particle reference using identical schedule and environment, reporting per-species differences and cluster uncertainty rather than trajectory identity. Preselect observational endpoints and do not redefine margins after inspection. The first bounded diagnostic uses a two-cell-per-axis water box, a single OH configuration and eight pre-existing counts; it directly tests native Voxelizing re-entry conservation and does not constitute a chemistry comparison. Its expected native observed failure is 8 to 0, and it must be reported as such rather than a passed coupling test.

Resource caps: no full-dose run; at most eight processes, initial diagnostics one process, bounded two/few-packet fixtures. Do not use a cell resolution violating reaction-radius constraints as a validation result. Actual eligible schedules, oxygen settings, independent packet and chemistry replica counts, endpoint times and errors must be recorded before chemistry comparisons; no comparisons have been run under this protocol.

No-recording crash diagnosis: the original 16x4 packet run had four reproducible access violations. A separate traced core showed the failing history reached a mesoscopic reaction, completed UpdateSystem, and faulted before Stepping returned. On the unchanged frozen core, adding a record time after the endpoint made all four failing seeds complete without changing the source schedule or random sampling. The original crashed batch is retained but is not accepted as a chemistry comparison; all histories must be rerun against the corrected core. A dedicated no-record reaction and empty-queue regression are required.
