The earlier coincident-copy stress was manually stopped after its working set reached about 10.78 GB; it was not killed by the harness. Before rerunning, instrument the exact 8-packet stress with flushed phase markers and process working-set readings, and enforce an external 512 MiB working-set cap, a 30 s timeout and a 3 GiB system-free-memory floor. Termination is a censored diagnostic, not a success or a scaling estimate. The input is the same library0/holdout0 pair with four exact coincident copies of each packet, seed 92001. Record the last phase and sampled peak; do not infer a root cause from overlapping source coordinates alone. A separate bounded cost control will use distinct original packets rather than repeated exact coordinates.
Distinct-packet bounded cost protocol, fixed before execution: use the first N/2 library and first N/2 holdout packets, N=2,4,8, with each original packet imported exactly once at its recorded position (no translation), delay 199 ps and 203 ps observation. Run seeds 93001–93003 serially per N, stopping any process above 512 MiB working set, at 30 s, or when system free memory falls below 3 GiB. Measure setup and each chemistry phase separately plus baseline/peak working set; preserve failures/censored runs. This is a small 4 um fixture, not a fit or projection to the requested 0.5 mm full-dose experiment.
Coincident-finder isolation, specified before execution: construct two, three and four same-species e_aq tracks at exactly the same coordinate, and matched controls at distinct 0.1 nm-spaced coordinates. Build only Geant4's native chemical octree finder, recording flushed entry/exit markers, with no particle reaction loop. Each subprocess uses a hard 256 MiB job-memory cap and a 5 s time cap; report any cap or crash as censored/failure, never as a passed test. This isolates a source-supported hypothesis, not full packet chemistry or independent beam sampling.
