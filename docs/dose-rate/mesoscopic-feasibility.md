# Mesoscopic recurring-source feasibility — completed investigation

The accepted ticket-2 particle reference is the comparison baseline. This investigation does not authorize production use or a full-dose run. The experimental candidate, assumptions, fixed initial fixture, ordering and resource caps are specified in [MesoProtocol](../../test/timed-injection/probe/MesoProtocol.md).

## Native source audit and measured re-entry failure

In Geant4 11.4.3 `G4DNAEventScheduler::Initialize` voxelizes once and builds Gillespie events; `Run` ends by clearing the initialized flag. A subsequent `Voxelizing` replaces the mesh and assumes a homogeneous old mesh. Its old-mesh loop assigns only `remainder` boxes with `base+1` molecules and omits all other `base` allocations. The isolated two-cell-per-axis diagnostic placed eight OH molecules in an old cell, called the native public `Voxelizing`, and measured 8 before and 0 afterwards (`08-meso/reentry.log`). This is a failure demonstration, not a coupling test pass. `ReVoxelizing`, by contrast, sums old cell maps into the coarser cell; its use still requires event-queue and boundary validation.

`Stepping` reads the next event time before returning when it exceeds end time. `RunInMesh` subsequently advances its global time to that event even if the event was not executed. When the event set is empty its outer run can fail to advance. `RecordTime` is invoked from a reaction step only and records at most one boundary; it cannot provide correct source/observation scheduling through jumps or quiet intervals. `Reset` removes mesh and events and resets equilibrium state. The Gillespie sampler stores events by cell, while a shared scavenger pool can change after reaction; affected rates may span the mesh. A correct source-boundary adapter therefore needs a single ordered absolute timeline, a state snapshot at observation times, bulk continuity and global propensity invalidation whenever the pool changes.

Directly voxelizing the 1 ps packet is chemically invalid: those records include modified, stop-but-alive H2O before at-rest dissociation and electron-hole recombination. `G4DNAGillespieDirectMethod` dispatches table reactions and diffusion jumps; it does not dispatch the molecular at-rest processes. Thus old/new particle chemistry must include native precursor processing, or an independently validated equivalent must be developed. The whole-state reconstruction candidate is a hypothesis to test, not an established solution. `G4Scheduler::Process` resets its clock and by default the scavenger, calls `EndProcessing` before `EndTracking` and clearing tracks, and so any repeated-cycle adapter must explicitly preserve pool contents, capture all survivors and clock state, and avoid duplicate counters. It must check no unresolved precursor or delayed track remains at mesh transfer.

The native mesh omits outward diffusion neighbors. Particle Brownian transportation in this project has not been shown to share that boundary behavior. Out-of-box positions must not be clipped; compatible boundaries or a justified interior regime require separate validation. Geant4 reaction-radius warnings must also be treated as a resolution constraint, not silently dismissed.

## Scale context

For the 0.5 mm cube, the eight-packet mean deposited energy is 0.0966198 MeV (SE 0.0111651 MeV), giving about 8.075 million primaries/s per Gy/s; a t(7) interval based on this small sample maps to approximately 6.34–11.11 million/s per Gy/s. Ten Gy corresponds to about 80.75 million expected primaries, with exposure times 10, 1, 0.1 and 0.01 s at 1, 10, 100 and 1000 Gy/s. Mean global gaps are about 123.84 ns, 12.38 ns, 1.238 ns and 123.84 ps respectively. These are calibration arithmetic, not runtime or spatial-overlap estimates; the finite library and beam sampling remain limitations. Relaxation windows long compared with the gaps can leave the system predominantly in its expensive particle phase.

In the initial 25 nm-cell toy, Geant4's OH diffusion coefficient is 2.8e-9 m²/s, and h²/(6D) is about 37 ns. Reconstructing after only 1 ps discards subcell spatial correlations far earlier than this dimensional scale. That scale is not an accuracy guarantee; it underscores why a passing population budget alone cannot justify chemistry equivalence.

## Bounded results so far

The corrected private scheduler passed a 32-seed no-source queue comparison against native mesoscopic stepping with unchanged bulk: exact occupied-cell/species states agreed. A nonreacting H2 budget was 8 before the source and 11 after three arrivals, and remained 11 after a 160-to-80-cell-per-side coarsening. An empty queue advanced exactly to the requested boundary. A deliberate single-cell reaction with no registered recording times completed; this exposed and guards the native scheduler constructor's uninitialized recording iterator. Four reproducible packet-cycle access violations in the initial ensemble occurred after a mesoscopic reaction update; initializing an unused later record rescued the same inputs on the frozen old DLL. Initializing the iterator in the private constructor likewise rescued all four without the workaround. The original crashed ensemble is preserved and is not interpreted.

An initial boundary test found that, for a box [-2,2] um and proposed coordinate 7 um, native rebound transport returned 3 um outside while the UHDR dissociation helper returned -1 um. The private candidate uses one periodic fold for both. Six-face single/multiple-crossing expected-coordinate tests pass. Native Brownian runs recorded actual outward proposed steps on all six faces and retained in-box survivors. Native H2O+ dissociation invoked the bounded action, resolved the precursor and produced in-box survivors on all six faces. Native dissociation first caps product displacements to 0.8 times navigator safety; the initial 64-seed attempt to observe an outward dissociation proposal found none and was replaced with the meaningful action-invocation control, not counted as an observed crossing.

A deliberately extreme 25 nm-cell stress test inserted a second electron 0.001 ps after the first. For the near-contact configuration, all 64 uninterrupted particle histories ended with zero electrons, while all 64 reconstructed-cell histories ended with two. In the same-cell far configuration, both arms ended with two in all 64 histories. Each 64/64 or 0/64 proportion has an individual two-sided 95% exact binomial interval of approximately [0.944,1] or [0,0.056], respectively. This demonstrates the loss of near-contact information under that very early handover; it does not by itself quantify a matured handover or beam prediction. All 256 histories completed and loaded the private runtime.

A separate 4 um-cube oxygen-free packet comparison used 16 independent physical packet pairs and four paired chemistry replicas per pair, at matched source times and 203 ps observation. Both arms used the same reflecting post-import boundary. All 128 corrected histories completed with matching source/energy/mass budgets, correct private DLL inventories and unchanged frozen hashes. Cluster means of cycle minus uninterrupted particle yields were +0.141 OH radicals (t15 95% interval [-1.367,1.648]), -0.141 solvated electrons ([-0.962,0.680]) and 0 H2O2 ([-0.454,0.454]). These exploratory intervals do not establish accuracy or equivalence. The 4 um geometry, small library, 100 ps initial particle handover, 25 nm cells and untransformed packet sampling limit the result. Full paired records and within-pair replicas are preserved in `08-meso/packet-comparison-16x4-fixed`.

For a bounded cost stress using coincident untransformed copies of one 4 um packet pair, three 2-packet histories took 5.39–6.33 ms in measured post-initialization chemistry with process peak working set 27.37–27.90 MB; three 4-packet histories took 12.81–15.04 ms and peaked at 28.42–28.54 MB. Process initialization alone took 0.111–0.132 s. The first 8-packet history did not finish: it was stopped after an observed working set of approximately 10.78 GB as free system memory fell to approximately 0.41 GB. That censored observation and highly overlapping copied sources do not support a scaling law or a full-beam runtime estimate. A later 512 MiB-capped trace localized the first cap to the first particle phase; it did not prove the cause.


## Decision and limits

**NO-GO for the requested 0.5 mm, 1–1000 Gy/s, up-to-10 Gy application.** The candidate can preserve a single ordered mesh/particle timeline in bounded controls, but its scientific accuracy, finite-library bias, recurring reconstruction cost and full-scale feasibility remain unestablished. No equivalence margin was specified. In the early-handover stress it demonstrably loses near-contact reactions. The particle finder also has a severe exact-coincidence limitation. These results do not exclude a future restricted regime after independent validation.

The late and oxygen matrix comprises 192 complete histories: eight physical pairs, four chemistry replicas and two arms for oxygen at 199 ps, and oxygen-free and oxygenated at 39999 ps. In the 40 ns conditions, cycle minus particle electron means were +2.188 (t7 interval [0.039, 4.336]) without oxygen and +1.969 ([0.419, 3.519]) with oxygen; oxygenated OH was +3.844 ([0.254, 7.433]). At 199 ps with oxygen the electron difference was +1.469 ([-0.278, 3.216]). These are exploratory marginal intervals over eight physical clusters, not multiple-comparison adjusted or accuracy bounds. The oxygen pool in this dilute exposure is not evidence of depletion.

Matched old-only and fresh-only controls for the near-contact fixture completed 256 single-source histories, plus the earlier 128 shared histories, with 64 seeds per arm. Shared-two electron yield minus the two matched singles was -2 for all 64 uninterrupted histories and 0 for all 64 cycle histories. The corresponding empirical paired standard errors are zero in this deterministic observed sample; this is not a zero population uncertainty interval. This nonadditivity is not an ancestry-labelled reaction count and the deliberately 0.001 ps mesh interval is not a realistic beam prediction.

Handover and resolution sensitivity used eight physical pairs and four replicas: 50, 100 and 150 ps initial handovers, and 20, 25 and 50 nm cells. Intervals were broad and do not establish convergence. For example, 150 versus 100 ps at 25 nm changed OH by +0.688 (t7 interval [-0.991, 2.366]); 20 versus 25 nm at 100 ps changed OH by +1.000 ([-0.876, 2.876]). The 12.5 nm candidate was rejected by the reaction-radius gate: 4.5117 nm was the first offending radius printed, not necessarily the maximum. The 20 nm setting passed the complete gate. Nested prefixes of 4, 8 and 16 physical pairs with 1, 2 and 4 replicas illustrate library versus history precision, but are correlated post-hoc subsets, not independent library-size experiments and not a finite-library bias correction.

With distinct original packets, all nine 2/4/8-packet runs (three seeds each) completed: mean measured chemistry time was approximately 0.0244/0.0242/0.0341 s and peak working set 27.5–29.8 MB. These tiny observations do not justify a scaling law. Six 256 MiB hard-cap native-finder controls found two identical e_aq positions completed, while three and four identical positions hit the cap inside finder construction; two, three and four distinct positions completed. The source octree has a two-item node threshold and inclusive child boxes that can duplicate entries at degenerate bounds; that is a plausible mechanism, not a completely traced root cause. Its zero-distance query also skips all zero-distance neighbours, not just the querying track. A separate kernel investigation should test deterministic child ownership, a degenerate vector leaf and identity-aware queries against brute-force/native contact controls. No production kernel fix is proposed here.

The three-source stable-H2 control passed 16 seeds: old population 1 at 1 ps, reconstructed at 2 ps, arrivals at 2 and 2.001 ps in the same particle run, three survivors at 5 ps and at 6 ps, with no future activation early. This validates the ordered mechanism in that fixture, not packet chemistry accuracy. Whole-state reconstruction is O(old population), loses subcell correlations and individual ancestry, and uses particle and mesoscopic models with different stochastic details. Recorded observations and physics scoring still require production-grade validation. Precursor capture at 1 ps cannot represent omitted earlier inter-track interactions; rates with physically important sub-picosecond overlaps are outside the tested regime.

## Reproduction and evidence

Use an isolated copy of the configured 11.4.3 source and a separate install, never the shared source or install. Apply `source-contacts-experimental.patch` first, then `meso-boundaries-experimental.patch`, then `meso-bulk-instrumentation-experimental.patch` from `patches/geant4/11.4.3/timed-injection/` using `git apply` in the private source. The last patch adds only event peeking and a thread-local refresh counter. Configure and build Geant4 with the same compiler/options as the configured installation and install it privately; configure `test/timed-injection/probe` with that private `Geant4_DIR`, `-DPROBE_PRIVATE_ACTIVATION=ON`, `-DPROBE_MESO_EXPERIMENT=ON`, and `-DPROBE_MESO_PRIVATE_BIN=<private-install>/bin`, then build all targets. Put the private bin and dependency DLL directories first on `PATH`. Use the project's MSVC setup in `.claude/geant4-instructions.md`. Run:

```powershell
ctest --test-dir <private-probe-build> -L injection-coupling --output-on-failure --no-tests=error
ctest --test-dir <private-probe-build> -L injection --output-on-failure --no-tests=error
```

The tracked protocol files beside the probe specify fixture commands, seeds, budgets and analysis. Experimental raw evidence resides in `.scratch/tests/2026-11-06__timed-track-injection-dose-rate-feasibility/08-meso`; it is local and ignored, so archive it separately for an independent replication. Results above identify the physical clusters, sampling and estimands rather than depending on a hidden script for interpretation. Frozen completed ensembles used private core SHA-256 `F86427564320D58E58209ED627B11F57A57DA6753EF4BFE6743B4563B09360E2`; the later bulk instrumented core is `75075C28022B0ED5487AFAF35554396B48B7FE0ECB600AA2A79E111634CCD970` on this build. The old DLL, header and corresponding source patch are preserved in `08-meso/frozen-core-f864`. Build hashes are machine/compiler specific.

The engineered bulk control set the private oxygen pool to 1,000,000 molecules, observed 999,999 after a mesh reaction, 999,999 after a particle phase using `ResetScavenger(false)`, and 999,998 after the subsequent mesh reaction. The respective whole-queue bulk-refresh counts were 1 and 2. The nominal initial pool was approximately 10.52 million; the engineered depletion is a control, not a measured beam prediction.

Instrumented and frozen cores agreed on the occupied-cell result in a selected unchanged-bulk no-source seed. A selected same-seed packet run differed between cores, and a repeat on the instrumented core also differed from its own preceding result. Thus exact packet trajectory parity is not established; the recorded instrument patch adds an event-time accessor and thread-local counter around an existing refresh branch, but this observation does not prove stochastic equivalence. The original ensembles remain attributed to their frozen F864 core, not the later instrumented build.

For the 16-pair oxygen-free comparison, `TrackCapture4um <MesoFixture4um.in> direct <prefix> <physicsSeed> <sourceSeed> <chemistrySeed>` produces each packet. For `library[i]`, use seeds `101001+101*i`, `202001+103*i`, `303001+107*i`; for `holdout[i]` use `404001+109*i`, `505001+113*i`, `606001+127*i`, with i=0..15. Run `CombinedHistory4um <macro> <library.packet> <holdout.packet> <output> <seed> 0 199` and `MesoPacketCycle <macro> <library.packet> <holdout.packet> <output> <seed> 199` for each `seed=81001+101*i+1009*r`, r=0..3. For each pair and species compute cycle minus particle, average its four replicas, then calculate the mean and t15 interval across the 16 pair averages; do not treat 64 replica differences as 64 independent physical pairs. Check source counts, deposited energy, cube mass, DLL inventory and return codes in every run. The oxygen and late fixtures and seed changes are specified in [MesoProtocol](../../test/timed-injection/probe/MesoProtocol.md).

The original 500 µm packet library can also be supplied as `-DPROBE_PACKET_LIBRARY=<original-500um-validation-directory>`. With that option, `PrivatePacketHistories` and `PrivateCombinedControl` are registered; run them with `ctest --test-dir <private-probe-build> -R "^(PrivatePacketHistories|PrivateCombinedControl)$" --output-on-failure --no-tests=error`. Both passed separately after the 63-test suite, which did not include them. The original library in this run was `01-msvc/validation`, matching the ticket-2 private-build cache. Recording continuity remains tested only in the bounded controls described here.
