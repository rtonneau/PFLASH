# Switch Geant4 11.4.1 → 11.4.3, drop the compile-commands hook and the KB tooling

## Context

Geant4 11.4.3 (`C:\DEV\GEANT4\geant4-11.4.3.tar.gz`) replaces 11.4.1. To make the switch smooth:
- clean up first (old 11.3.2 trees, the KB tooling);
- build 11.4.3 next to 11.4.1, so 11.4.1 stays available for rollback;
- move the environment over, then verify dnachem-min on 11.4.3 before any doc says "verified with 11.4.3".

Also requested:
- remove the PostToolUse hook `update-compile-cmd.ps1`. It writes `hook-posttooluse.log`, which is tracked in the public repo despite `.gitignore`, and it reconfigures CMake after every C++ edit;
- remove everything related to the "kb" (Geant4 extra docs).

Decisions taken in the grill:
- delete only 11.3.2;
- **flat** source layout: `geant4-v11.4.3-source/` holds `CMakeLists.txt` directly;
- `git rm` all of `.kb-notes/`;
- clean the template repo too, on a new branch.

Facts checked:
- the 11.4.3 tarball lists the same datasets as the ones installed (G4EMLOW 8.8, G4NDL 4.7.1, …). `Geant4-ressources-data` is reused; only the optional G4TENDL/NUDEXLIB/URRPT are absent, as they are today;
- nothing references 11.3.2;
- the user PATH holds `…\geant4-v11.4.1-install\bin`, and `setup-dev-env.ps1` does not edit PATH;
- `/build-geant4` is not installed in `~/.claude/commands`, so `build-geant4.ps1` is called directly.

Step 0: copy this plan to `dnachem-min/.claude/plans/2026-11-04-geant4-11.4.3-switch.md` (project rule).
